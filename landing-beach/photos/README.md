# Shot list

Drop a file here with the exact name below and it appears on the page — no code
change. Until a file exists the frame shows its brief instead, so a missing
photo is visible rather than an empty box.

Nothing on this page uses stock imagery. It sells membership of one specific
club; another club's pool on it would be a claim about a place that doesn't
exist.

## Practicalities

- **Format** JPG or WebP. WebP is roughly half the size at the same quality.
- **Width** 2000px is plenty; the largest frame is ~1400px on a wide screen.
- **Weight** aim under 300 KB each. This page is 32 KB — thirteen careless
  photos would make it 20× heavier and undo the reason it isn't part of the
  main app.
- **Faces** get permission before putting members on an ad landing page.
